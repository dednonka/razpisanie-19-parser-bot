# Расписание школы — Telegram-бот

Бот сам следит за папкой в Облаке Mail.ru, куда школа выкладывает расписание
в виде `.xlsx`, и раздаёт его в Telegram по кнопкам: дата → класс → буква.

## Что умеет

- Автоматически подхватывает новые файлы в папке и убирает удалённые —
  ничего руками обновлять не нужно.
- **Замечает правки в уже загруженных файлах.** Если в облаке заменили файл
  с тем же именем (например, поправили расписание на завтра), бот это
  увидит и обновит данные при ближайшей проверке (раз в 10 минут) или по
  команде `/update`. Подробнее — в разделе «Как бот ловит изменения».
- Понимает и обычные файлы «на один день», и файл-мастер сразу на всю
  неделю (с блоками ПОНЕДЕЛЬНИК/ВТОРНИК/... внутри одного листа) — он
  показывается отдельной кнопкой с выбором дня недели.
- Корректно разбирает объединённые ячейки: актовый зал на несколько
  классов, экскурсии на весь день, подгруппы предмета через `/`.
- **По понедельникам первой строкой всегда стоит** `0. 8:00 - 8:30 Разговоры о важном`
  у всех классов, у которых в этот день есть уроки.
- **Пропуски («окна») показываются явно**, а не просто пропускаются:

  ```
  3. 10:10 - 10:50 русский 24 каб
  4. -
  5. 11:50 - 12:30 физика 7 каб
  ```

  Пропуски заполняются только между первым и последним уроком дня.
- Поиск «когда у класса будет физика» — показывает ближайший день по
  недельному расписанию.
- Обратный отсчёт до каникул / до конца каникул (даты в `school_calendar.py`,
  редактируются вручную раз в год).

## Файлы

| Файл                       | Зачем                                                                                                                          |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| `schedule_bot.py`          | Парсер xlsx + вся логика экранов + версия бота на обычном `requests` (для сети без блокировок)                                 |
| `schedule_bot_mtproto.py`  | То же самое, но подключается к Telegram через локальный MTProto-прокси (Telethon) — для сетей, где Bot API напрямую недоступен |
| `school_calendar.py`       | Даты каникул — единственное, что нужно обновлять руками раз в год                                                              |
| `test_change_detection.py` | Проверка без сети: ловит ли бот правки в файле, показывает ли «Разговоры о важном» и пропуски                                   |

## Установка

```
pip install requests openpyxl
# для mtproto-версии дополнительно:
pip install telethon
```

## Запуск

**Вариант 1 — прямой доступ к Telegram:**

```
export BOT_TOKEN="токен"
python schedule_bot.py
```

**Вариант 2 — через локальный MTProto-прокси** (например, при региональных
ограничениях на Bot API):

```
export BOT_TOKEN="токен"
export API_ID="с my.telegram.org"
export API_HASH="с my.telegram.org"
export MTPROXY_SECRET="секрет прокси"
export MTPROXY_PORT="порт прокси"
python schedule_bot_mtproto.py
```

Проверить парсер отдельно, без запуска бота:

```
python schedule_bot.py --debug
```

### Запуск на телефоне / планшете (Termux)

Чтобы Android не усыплял бота в фоне:

```
termux-wake-lock
```

и отключи для Termux оптимизацию батареи в настройках Android.

Бот сам поднимается после падения:

```
while true; do python schedule_bot_mtproto.py; sleep 5; done
```

Если хочется ещё и перезапускать его раз в двое суток (на всякий случай):

```
while true; do timeout 172800 python schedule_bot_mtproto.py; sleep 5; done
```

Бот почти не занимает память (десятки мегабайт), так что перезапуск —
это страховка, а не необходимость. Сессия `bot_session` хранится на диске,
повторно входить в Telegram после перезапуска не нужно.

## Как бот ловит изменения

Раз в 10 минут (`REFRESH_SECONDS`) и по команде `/update` бот:

1. получает список файлов из папки в облаке;
2. **скачивает каждый файл целиком** и считает SHA-256 от всего содержимого;
3. сравнивает хэш с тем, что запомнил в прошлый раз:
   - хэш совпал — файл не менялся, ничего не делает;
   - хэш другой (или файл новый) — разбирает файл заново и заменяет данные;
4. файлы, которых в папке больше нет, удаляет из своей базы.

Если новая версия файла не скачалась или не разобралась, остаётся прежняя,
а в логе появляется ошибка. Один «плохой» файл не мешает обновлению остальных.

Проверка `PK` в начале файла (`download()`) нужна только чтобы отличить xlsx
от html-страницы с ошибкой — на обнаружение изменений она не влияет.

## Как проверить, что изменения ловятся

**Без сети (быстро, 5 секунд).** Из папки с ботом:

```
python test_change_detection.py
```

Скрипт сам создаёт xlsx, меняет в нём один урок и проверяет, что бот это
заметил. Должно быть девять ✅ и код выхода 0.

**На настоящей папке.**

1. Запусти бота и открой любое расписание — запомни один из уроков.
2. В облаке замени файл с **тем же именем**, изменив один урок.
3. Отправь боту `/update` (или подожди до 10 минут).
4. В логе консоли должна появиться строка `Файл изменился: <имя файла>`.
5. Открой то же расписание в боте — урок должен быть новым.

Если строки в логе нет, а урок старый — значит, бот получил тот же файл
(например, облако ещё отдаёт старую версию из кэша).

## Настройка под свою школу

- В `schedule_bot.py` в константах `KEY_PART1`/`KEY_PART2` (или `FOLDER`) —
  ссылка на публичную папку Облака Mail.ru.
- В `school_calendar.py` — актуальные даты каникул.
- На главном экране бота под отсчётом до каникул показывается погода для
  Кургана:
  - **Источник** — [wttr.in](https://wttr.in), без ключей и регистрации.
  - Запрашивается **компактный текстовый формат** (`%t|%h|%w|%C`), а не
    полный JSON (`format=j1`) — на сетях с ограничениями крупные ответы
    иногда обрывались на середине, короткая строка долетает надёжнее.
  - Кэш на 15 минут (`WEATHER_TTL` в `schedule_bot.py`) — чтобы не дёргать
    wttr.in на каждый `/start`.
  - При любой ошибке сети строка погоды просто не показывается — бот
    никогда не падает и не виснет из-за недоступной погоды.

**Под свой город:** поменяй `KURGAN_LAT`, `KURGAN_LON` в `schedule_bot.py` на координаты нужного города.

**Пороги смайлов температуры** (там же, в `weather_line()`):

```
if temp < -15:   # ❄️
elif temp < 15:  # 🥶
elif temp < 24:  # 🌡️
else:             # 🥵
```

## Безопасность

Токен бота, `API_HASH` и секрет прокси задаются только через переменные
окружения и нигде не хранятся в коде — не коммить их в файл и не пишите
напрямую в скрипт.
